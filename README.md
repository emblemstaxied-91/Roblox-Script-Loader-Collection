## FAQ

### Is XCutors safe to use?

XCutors itself is a loader and management tool. The safety of executing scripts depends on the scripts you choose to run. We recommend using scripts from trusted sources only.

### Do I need to disable my anticomponent?

Some security software may flag script executors due to their nature. You may need to add exceptions for the installed files, but this is user discretion.

### How do I update the executors?

XCutors checks for updates automatically on launch. You can also manually check from the settings menu to download the latest versions of each executor.

### Can I use custom executors not included?

Yes, the universal loader supports adding custom executors manually through the advanced configuration menu.

### What Windows versions are supported?

XCutors is designed for Windows 10 and Windows 11. Some older versions may work but are not officially supported.

### Are scripts executed locally?

Yes, all script execution happens locally on your machine through the selected executor.
